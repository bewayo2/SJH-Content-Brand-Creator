# Identity and naming

- Official name: **St. Jude Hospital**.
- Use the full name on first reference.
- Approved short name: **SJH**, only after the full name has appeared in the same communication.
- For external, regional, international, donor-facing, web and search-facing material use **St. Jude Hospital, Saint Lucia**.
- Do not use **St. Jude** alone in formal external communication.

Use one approved name for every department, service, ward, unit and programme. Patient-facing materials should use approved patient-friendly service names. Do not invent alternate department identities, programme names, corridor names or zone systems.

Avoid unexplained acronyms in patient-facing material. Introduce the full term first, then the acronym if needed.

Flag as REQUIRED CHANGE: incorrect institutional naming, SJH before the full name, unexplained patient-facing acronyms, or unapproved service/department naming.
