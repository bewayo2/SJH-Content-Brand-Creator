# Document design specialist reference

Use this reference when creating or reviewing decks, dashboards, reports, guides, brochures, patient handouts, formal documents, and other designed information artifacts.

## Core stance
Design is not decoration added after the fact. Solve the information problem first, then elevate the result.

## Default workflow
1. Build the most functional version first.
2. Establish hierarchy and flow.
3. Remove noise.
4. Strengthen typography, spacing, and alignment.
5. Introduce deliberate emphasis.
6. Refine colour and graphic treatment.
7. Review the whole system for consistency and craft.

## What strong document design should achieve
- The viewer understands the main point quickly.
- Important actions are obvious.
- The page or slide has a clear entry point.
- Related information is grouped.
- The structure can be scanned before it is read.
- Visual treatment supports trust and clarity.
- The work feels authored, not auto-generated.

## Key domains
### Layout
Use a clear grid. Prefer strong left alignment for information-heavy content, consistent top edges, and enough margin to create calm.

### Typography
Use type to create order. Decide display, section, body, caption, and data-emphasis levels. Use contrast in size, weight, spacing, and density. Do not rely on colour alone for hierarchy.

### Spacing
Use spacing to separate ideas, create breathing room, and show grouping. If everything is equally close, nothing is grouped.

### Colour
Use colour to identify brand, emphasis, and data states. Lead with the approved SJH palette. Use bright green as an accent, not body text.

### Dashboards
A dashboard must answer: what matters most, what changed, what needs attention, and what action follows. Surface the primary KPI first. Avoid chart junk.

### Presentations
Strong decks behave like paced editorial documents. Each slide should have one main purpose and a clear focal area.

## Final test
A finished designed document should feel clear, confident, calm, structured, intentional, and distinctly non-generic.
