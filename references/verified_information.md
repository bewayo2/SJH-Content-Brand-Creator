# Verified information

Brand rules are relatively stable; operational facts are not. Do not treat old collateral or the Brand Bible as automatic proof of current operational information.

Verify current facts before public release, including:
- telephone numbers;
- institutional email addresses;
- website domains;
- postal/physical addresses;
- service hours;
- opening/closure dates;
- service availability and readiness;
- current department/service names where still provisional;
- current office-holders;
- current programmes;
- current official social accounts.

## Drafting rule
If a current fact is not verified:
- do not guess;
- use a clear placeholder if a draft is still useful;
- list the item under **Items to verify before release**;
- do not make the final-facing artifact sound confirmed.

User-supplied facts may be used as user-supplied draft content, but should not be labelled independently verified without an authoritative source.

Maintain a separate controlled verified-information register with fields for the fact, approved value, source, owner, verification date and next review date.
