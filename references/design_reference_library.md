# Design reference library

Use these references for principle-level design intelligence. Borrow the underlying logic, never the branded expression.

## Stripe
Useful lessons: systematic but lively composition, clear hierarchy, modular layouts that still feel human.

## Linear
Useful lessons: precision, tight typographic hierarchy, disciplined spacing, minimal confident interfaces.

## Apple
Useful lessons: reduction, elegant whitespace, clear focal points, premium pacing, disciplined restraint.

## Bauhaus
Useful lessons: function first, geometry with purpose, clarity through simple forms, visual economy.

## Swiss / International Typographic Style
Useful lessons: grid discipline, typographic hierarchy, asymmetrical balance, objectivity, and clarity.

## General rule
Translate the principle into the SJH context. Borrow logic, not surface styling.
