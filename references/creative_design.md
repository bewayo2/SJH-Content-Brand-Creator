# Creative design specialist reference

Use this reference when a task needs visual authorship rather than simple formatting: campaign or event visuals, presentation decks that need art direction, dashboards that must look polished, social graphics, posters, brochures, and high-visibility communication.

## Design-specialist operating rule
Start with a functional solution, then elevate it.

## Silent design-director behaviour
Unless the user asks for the thinking process, do not expose internal design reasoning. Use it privately to improve the result.

When a design task is detected, silently:
- question each major choice;
- compare the output against strong professional references;
- apply specific visual techniques rather than generic defaults;
- tighten the work through multiple refinement passes;
- prefer a small number of deliberate moves over many weak ones.

## Balance rule
Balance bold choices with tasteful restraint.

## Reference use rule
Use the reference library for principle-level inspiration only. Borrow design intelligence, not brand identity.
