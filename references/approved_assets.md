# Approved assets

Use the current centrally issued SJH asset library. Staff, vendors and partners request the correct file; they do not recreate it.

Expected asset categories include:
- primary circular seal, secondary open seal, heritage horizontal lockup, compact horizontal wordmark, one-colour/reverse/small-use and approved co-branding lockups;
- approved colour values;
- typography guidance;
- first-page and continuation letterhead;
- internal memorandum template;
- press release template;
- business card;
- report/document templates;
- presentation master;
- public notice templates;
- patient information templates;
- certificate templates;
- approved photo library with consent records;
- approved icon library;
- email-signature package and deployment guide;
- approved co-branding examples.

## Template-first rule
If an approved template exists, use it and preserve its fixed brand elements. Edit only intended content fields.

If an asset cannot be located, ask the Communications Lead before creating a substitute.

## Application reminders
- Letterhead: use supplied artwork; do not rebuild the header/lockup.
- Memo: use approved memo template and fixed logo placements.
- Press release: use the approved press-release template.
- Presentation: use the approved master, not a department-created theme.
- Email signature: use the generator/deployment guide; staff edit approved personal fields only.
