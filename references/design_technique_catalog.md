# Design technique catalog

Use this catalog to choose specific visual moves based on what the design needs to achieve.

## To create clarity and order
- Strong grid with disciplined alignment.
- Fewer component types.
- Clear section bands or spacing breaks.
- Left-aligned text blocks for readable information-heavy content.

## To create hierarchy
- Scale contrast between headline and support copy.
- Weight contrast rather than many colours.
- One dominant visual region per page or slide.
- Pull the key metric, quote, or action out of the flow.

## To make a design feel premium
- Larger margins and more breathing room.
- Quiet neutrals supporting one strong primary colour.
- Tightened typographic system.
- Precision in padding, corners, lines, and component repetition.

## To improve dashboards and data views
- Put summary metrics first.
- Use aligned cards instead of unrelated boxes.
- Label directly where possible.
- Use colour sparingly to highlight changes.

## To elevate presentations
- Convert topic headings into message headings.
- Give each slide one core message.
- Create rhythm by alternating density.
- Refine chart styling to reduce default-software appearance.
