# Design elevation protocol

Use this protocol to move from competent output to polished output.

## Phase 1 — Functional foundation
Create the clearest workable version first.

## Phase 2 — Structural refinement
Simplify the composition, strengthen the grid, improve grouping, and make the primary message dominant.

## Phase 3 — Typographic refinement
Reduce unnecessary styles, strengthen contrast between levels, and improve line lengths and spacing.

## Phase 4 — Spatial refinement
Build spacing rhythm, add breathing room where needed, and use space to create emphasis.

## Phase 5 — Colour refinement
Reduce colour noise, clarify dominant colour role, and ensure accessibility.

## Phase 6 — Graphic refinement
Remove default chart styling, refine icons/panels/dividers, and improve image crops and scale.

## Phase 7 — Signature move
Add one controlled move that gives the piece authorship.

## Phase 8 — Consistency pass
Align margins and paddings, normalize component behaviour, and unify titles/captions.

## Phase 9 — Final interrogation
Use `references/design_interrogation_checklist.md`.

## Delivery rule
Return only the polished result unless the user asks to see the design thinking process.
