# Controlled source documents

The institutional source documents used by this skill are intentionally not stored in this public repository.

For deployment, connect or attach the current approved versions of:
- St. Jude Hospital Brand Bible — highest authority;
- St. Jude Hospital Visual Brand Guide;
- St. Jude Hospital Staff Brand Guide / Quick Reference;
- current approved templates and master artwork;
- current specialist standards, such as signage, digital, photography/consent or clinical patient-information standards;
- current verified-information register and approval matrix.

Do not rely on an old exported copy when a newer approved institutional version exists. When a source changes, review the distilled `references/` and `playbooks/` before redeployment.
